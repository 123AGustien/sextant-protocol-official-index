# Appendix F — World Bank / IMF Mapping Layer (v1.0)

## 1. Purpose

This appendix maps the Sextant Protocol framework onto global financial governance institutions for conceptual alignment with macroprudential oversight systems.

---

## 2. Institutional Nodes

Define institutional set:

I = {
World Bank Group,
IMF,
BIS,
Central Banks,
National Regulators
}

---

## 3. Functional Mapping

Each institution maps to system function:

- World Bank → structural development resilience
- IMF → liquidity stabilization + crisis intervention
- BIS → global banking coordination layer
- Central Banks → monetary system controllers
- Regulators → compliance enforcement nodes

---

## 4. Mapping Function

Let:

M(i) → system role projection

Where:

S(t) → institutional stress input

Then:

Response(i) = M(i) × S(t)

---

## 5. Stress Translation Layer

System stress is translated into policy response signals:

Policy_response = f(Financial Stress, Time Delay, Institutional Capacity)

---

## 6. Observability Gap

Define:

OG = Time(system shock) − Time(policy response)

Higher OG = higher systemic risk exposure

---

## 7. Interpretation

This layer shows:

- how global institutions respond to cascade stress
- delay in macroprudential intervention
- structural governance coupling effects
